## 📋 Resumo Geral
**Neeexusbr Games** é uma plataforma web completa de jogos online com sistema de progressão, comunidade interativa, loja, achievements e múltiplas funcionalidades gamificadas. Criada por Dogue, é uma aplicação rica e bem estruturada para entretenimento e aprendizado.

---

## 🎯 FEATURES PRINCIPAIS DO SITE

### 1. **SISTEMA DE JOGOS** 🎮
- **40+ Jogos Disponíveis** incluindo:
  - Arcade: GD Clicker, Geometry Dash Lite, UFO, Wave Game, Snow Rider 3D, Block Blast, Talking Ben
  - Aventura: Undertale Barato, Level Devil, Koopa Revenge 2, Tomb of the Mask, Super Mario 64, Racing, Minecraft
  - Ação: Ultrakill, Roube um Brainrot, Call of Duty, Tanki Online, Bad Time Simulator
  - Horror: FNAF 4, Granny, Baldi's Basics, Mad Time Simulator
  - Multijogador: Slither.io, Among Us, 2 3 4 Player Games
  - Ritmo: Friday Night Funkin
  - Educativo: Apostilas, Número Mágico
  - Secretos: Guloso, Flappy Div, Bruno, Jogos Indexados, Jogos Flash
- Sistema de abertura em modal com iframe fullscreen
- Botão "Destaque da Semana" com banner interativo

### 2. **SISTEMA DE USUÁRIO E AUTENTICAÇÃO** 👤
- Login/Logout com sistema de sessão
- Perfil de usuário customizável
- Foto de perfil editável (URL ou GIF)
- Nome de usuário exibição
- Painel de usuário lateral com botões de ação

### 3. **SISTEMA DE MOEDAS/GEMAS** 💎
- Display de gemas na navbar com animação hover
- Gemas como moeda principal do jogo
- Sistema de compra e ganho de gemas
- Histórico de compras rastreado

### 4. **LOJA INTERATIVA** 🛒
- **Loja do Sans** - Estilo Undertale com diálogo interativo
- **Loja do Spamton** - Personagem alternativo com diálogo único
- Grid de itens comprável
- Sistema de diálogo conversacional (Comprar/Conversar)
- Itens disponíveis:
  - Desbloquear todos os jogos
  - Tag personalizada
  - Escolher novo jogo
  - Skins e cores de borda

### 5. **SISTEMA DE CONQUISTAS/ACHIEVEMENTS** 🏆
- **4 Conquistas Principais:**
  - 🔍 **Detetive**: Clique no destaque da semana
  - 🍀 **Sortudo**: Use o botão "Estou com Sorte"
  - ♾️ **Infinidade**: Secreto (Reach infinity in GD Clicker)
  - ☝︎✌︎💧︎❄︎☜︎☼︎ **Gaster**: Encontre o Gaster no inventário
- Modal de exibição de conquistas com animações
- Sistema de desbloqueio progressivo
- Descrições dinâmicas baseadas no progresso

### 6. **CHAT EM TEMPO REAL** 💬
- Chat Global da comunidade
- Sistema de Mensagens Privadas
- Abas de navegação (Global/Privado)
- Histórico de conversas
- Display de usuário, timestamp e mensagens
- Notificação visual de novas mensagens

### 7. **RECOMPENSAS DIÁRIAS** 🎁
- Calendário de 30 dias
- Gemas como recompensa diária
- Bônus especiais em certos dias
- Status visual de dias (hoje, coletados, próximos)
- Cooldown de 24h entre coletas
- Display de próxima recompensa disponível

### 8. **SISTEMA DE LEADERBOARD** 🏅
- 3 Abas de ranking:
  - ⏱️ Tempo de Jogo
  - 💎 Gemas
  - 🎡 Giros na Roleta
- Posições com medalhões (Ouro, Prata, Bronze)
- Exibição de perfil e foto do usuário
- Sistema de recompensas por posição
- Scroll dinâmico para muitos usuários

### 9. **INVENTÁRIO DO USUÁRIO** 🎒
- **Cores de Borda de Perfil:**
  - 15+ cores disponíveis (Prata, Vermelho, Azul, Verde, Laranja, Amarelo, Verde Limão, Dourado, Roxo Neon, Ciano, Rosa Néon, Verde Neon, Azul Céu, Arco-Íris)
- Acesso à Roleta da Sorte
- Easter egg com Gaster (sprite escondido)

### 10. **SISTEMA DE ROLETA/WHEEL** 🎡
- Spinner visual com 8+ opções
- Giros limitados (resgatável)
- Sistema de Fast Spin (ativar/desativar)
- Recompensas variadas
- Animação de giro realista
- Personagens temáticos (Jevil, Door)

### 11. **SKINS CUSTOMIZÁVEIS** 🎨
- 4 Skins de tema disponíveis:
  - Sala do Futuro
  - Alura (Tema Noturno)
  - LeiaSP (Tema Cósmico)
  - Matific (Tema Futurista)
- Ativação via tecla `;`
- Salvamento de preferência no localStorage
- Modal de seleção de skins

### 12. **PAINEL DE ADMINISTRADOR** 🔴
- **Acesso por Nível:**
  - Admins: Gerenciar moedas (solicitar), perfil de usuários
  - Dono: Acesso total + Gerenciamento Avançado + Emergência
- **Funcionalidades:**
  - **Moedas & Jogos:**
    - Adicionar gemas aos usuários
    - Solicitar gemas (para aprovação)
    - Desbloquear jogos secretos
    - Adicionar itens
  - **Perfil de Usuários:**
    - Mudar tag do usuário (10 caracteres)
    - Mudar foto de perfil
    - Mudar cor de borda do perfil
  - **Gerenciamento Avançado (Dono apenas):**
    - Listar todos os usuários
    - Adicionar giros na roleta
    - Adicionar tempo de jogo
    - Promover admin
    - Remover admin
  - **Emergência:**
    - Botão de reset de emergência (reseta todos os admins)

### 13. **SISTEMA DE NOTIFICAÇÕES** 🔔
- 3 Abas:
  - 📋 Solicitações Pendentes de Gemas
  - 📝 Histórico de Solicitações (Aprovadas/Rejeitadas)
  - 🛒 Histórico de Compras
- Badge de contagem de notificações
- Status visual de solicitações (Pendente, Aprovada, Rejeitada)
- Botões de ação (Aprovar/Rejeitar)

### 14. **FILTRO E BUSCA DE JOGOS** 🔍
